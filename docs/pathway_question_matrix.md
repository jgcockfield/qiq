# Pathway Question Matrix Audit

## Scope

This audit compares the current question flows from these files:

- `app/engine/taxonomies/taxonomy_contractor.json`
- `app/engine/taxonomies/taxonomy_employee.json`
- `app/engine/taxonomies/taxonomy_business_owner.json`
- `app/engine/pathways/spain_dnv/questions.json`
- `app/engine/pathways/costa_rica_pensionado/questions.json`

Costa Rica DNV is the QIQ reference model for qualification-first question style and eligibility structure. It should not be refactored to match Spain DNV or Costa Rica Pensionado. Spain DNV and Costa Rica Pensionado should align toward Costa Rica DNV’s core flow while keeping pathway-specific requirements where they affect eligibility or review status.

## Remaining Missing Questions

### Spain DNV

- No remaining missing questions against the Costa Rica DNV baseline categories.

### Costa Rica Pensionado

- Missing dependent relationship and dependent age questions if Pensionado should mirror the full Costa Rica DNV dependent-detail pattern.

## Remaining Order Mismatches

- Spain DNV asks `routing.service_interest` before the qualification flow because it also routes tax-service interest.
- Spain DNV asks contractor service-agreement status before foreign-source income because it only applies when `routing.work_relationship == contractor`.
- Spain DNV keeps contact and consent fields after eligibility/final notes because they are inherited from the Typeform-style intake.
- Costa Rica Pensionado starts with `routing.applicant_type` because individual/family status drives dependent branching and there is no separate work relationship.
